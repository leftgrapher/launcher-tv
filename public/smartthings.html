Connecter SmartThings au launcher

Pour que les boutons du hub (Hue Sync, mode vidéo, mode gaming, toute la pièce) lancent tes routines SmartThings.

Avant de commencer

  1. Crée une appli « API Access » sur developer.smartthings.com/console (Service Integrations).
  2. URL de redirection :
  3. Autorisations : r:scenes:* et x:scenes:*.

1. Identifiants de l’appli

Ils restent sur ce téléphone le temps de l’autorisation, puis dans le code à coller sur ta TV. Rien n’est envoyé ailleurs qu’à SmartThings.

2. Une routine pour chaque bouton du hub

Les routines « à lancer manuellement » de ton compte SmartThings. Laisse « Aucune » si un bouton n’en a pas.

3. Code de connexion

Sur la TV, dans le panneau « Connecter SmartThings », sélectionne le champ et colle ce code avec le clavier du téléphone (notification de l’appli SmartThings), puis valide.

Ce code donne accès à tes routines : ne le partage pas. Il ne sert qu’une fois ; pour reconnecter la TV, refais ces étapes.
